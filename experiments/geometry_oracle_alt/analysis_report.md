# Geometry-Oracle ALT-30 结果与分析

本实验已完成；没有训练或加载任何神经网络。Oracle 在每次重规划时读取仿真器当前五维真实状态，属于 **Privileged Information**。它不是与视觉 ALT 同等输入的部署方案，也不是严格理论性能上界。

**主要结论：离线几何匹配和动作 RMSE 改善，但本轮闭环分数未优于原 ALT。相对原 ALT 与 B1 的两项配对置信区间都跨过零，不能声称闭环有明确提升。重复检索并未被真实状态输入消除。**

## 设置与验证

使用原冻结 split42 的 30 条训练 Episode、3,806 帧；20 条验证 Episode、2,426 帧仅用于离线查询。Bank 未包含验证帧。原始 float32 状态逐项一致，检索用 float64；周期角距离、确定性相同距离排序、自检索、全部帧动作边界、环境行为一致性和 Windows spawn AsyncVectorEnv 状态同步测试均通过。

距离固定为 `(dp/512)^2 + (dT/512)^2 + (wrap(dtheta)/pi)^2`，权重 1:1:1。Top-1、绝对动作、offset=0、8 步重规划、repeat-last padding；无补偿、混合或 OOD fallback。

正式评测仅执行一轮：官方 PushTImageRunner.run，冻结 Seeds 100000–100049，legacy_test=True、max_steps=300。主指标是各回合最大 `clip(coverage/0.95,0,1)` 的均值，不是最终覆盖率或二元成功率。

状态同步检查 1863 次，Oracle 与观察 pusher xy 最大差 0.00001523（float32 共享内存舍入）；五维状态与生成观察时捕获的快照完全一致。

## 实际统计：闭环控制

| 方法 | Mean Score | 重复同帧/相邻查询 | 同帧且推杆停滞/相邻查询 | 闭环推杆匹配误差 |
|---|---:|---:|---:|---:|
| 原 ALT-30 | 0.274423899 | 21.92% | 19.84% | 63.031 |
| B1 | 0.178184988 | 62.04% | 57.79% | 64.730 |
| Geometry Oracle | 0.224722502 | 70.22% | 65.69% | 47.369 |

重复比例分母排除每个回合首个查询，停滞定义为连续检索同一 Episode/Frame 且查询时刻的推杆移动 ≤0.001。它是描述性诊断，未用于策略决策。**查询时刻不动不等于动作块内没有运动：推杆也可能在 8 步内移动后返回同一位置，形成周期回路。** 三个方法的闭环状态分布不同，匹配误差不能视作同一批查询上的比较。原 ALT/B1 没有保存闭环 T 块真实状态，因此其闭环 T 位置/角误差不可恢复；上表之外的 T 匹配比较使用离线验证集。

Oracle 闭环 T 位置平均误差 64.447、角度误差 14.782°，高于其离线验证均值；说明测试中最近候选也可能相距明显，不能把 Oracle 最近邻称为完全准确的物理匹配。

Oracle 的 Score 标准差 0.312898，均值 bootstrap 95% CI [0.14338580081400698, 0.314000753505627]；平均最终分数 0.160493，总环境步数 14703。

同一 50 Seeds 的配对差异；固定随机种子 2026，10,000 次按 Seed 成对重采样的 percentile 95% CI：

- Oracle − 原 ALT: -0.049701，95% CI [-0.157576, +0.058016]；更高/更低/相同 Seeds = 14/24/12。
- Oracle − B1: +0.046538，95% CI [-0.029137, +0.125975]；更高/更低/相同 Seeds = 17/12/21。

该区间仅描述这些评测初始状态的不确定性，不涵盖视觉模型训练种子变化，也不代表调参后的总体最优结果。

## 问题回答与解释边界

1. **真实几何状态检索是否改善？** 相同离线查询上，Oracle 的推杆、T 位置、T 角度平均误差均低于原 ALT；动作 RMSE 也需单独看待。改善说明原视觉嵌入的几何区分确有不足，但直接读取真实状态本身也提供了更强的信息。

2. **闭环是否随之改善？** 本轮 Oracle Mean Score 为 0.224723，相对原 ALT 的差异为 -0.049701；数值低于原 ALT、高于 B1，两项区间均跨零。本轮没有支持闭环明确改善的证据，不能把离线更近直接等同于控制成功。

3. **剩余失败来自哪里？** 下列是分析推测，不能由本次单一实验确证因果：五维状态没有速度、接触历史和动作意图；最近示范帧仍有非零误差；8 步绝对目标回放在偏移状态上可能形成重复检索或循环。记录中的停滞/循环与这些机制相容，但不能单独区分它们。

实际轨迹中有 41/50 回合以至少 3 次同帧检索结束。前四个固定 Seed 中，100001/100002/100003 分别在末尾连续检索同帧 36/35/33 次；最后两次查询的五维状态差为零，但它们重复的动作块并非常量。`first_four_trace_inspection.json` 与 `seed100001_chunk_cycle.png` 给出可复核证据。100000 最后一次查询虽推杆误差约零，T 位置仍差约 58、角度约 35.8°，说明只让部分距离很小仍可能选到不相容动作。

本轮没有改变执行长度、引入动作相对平移或进一步做对照；因此不会把剩余失败全部归因于 8 步回放，也不会声称真实状态检索保证动作相容。
