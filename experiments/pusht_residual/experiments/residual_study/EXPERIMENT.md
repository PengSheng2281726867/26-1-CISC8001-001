# 检索加残差修正的三轮实验

## 研究问题与数据

用最相似训练帧的八步动作作为先验，测试小网络能否修正几何偏差。固定 Push-T v7 的 30 条训练示范（3,806 帧记忆库）、20 条预留示范和 50 个冻结测试种子。检索查询使用仿真器的推杆位置及 T 的真实位置与角度。环境奖励只用于评估。

每个训练查询排除自身整条轨迹。监督目标是该查询帧实际示范的八步专家动作。预留示范只作为查询，候选始终来自训练库。训练与验证只取能完整读取八步的查询。闭环的示范末尾使用同轨迹最后动作填充。时间对齐偏移为零。

## 模型与三轮决策

每轮对照均包含原始绝对动作、T 位姿对齐动作、对齐后加学习残差。对齐把示范动作转换到示范 T 坐标系，再转换到当前 T 坐标系对应的桌面位置。模型输入 24 维，依次包括两个局部推杆坐标、匹配 T 在当前 T 坐标系的中心差、周期角差的正弦余弦、匹配动作块。MLP 为 24 → 64 → 64 → 16，隐藏层用 ReLU，最后一层零初始化。输出是当前 T 坐标系中每步的二维修正量，叠加到检索动作后转回绝对桌面坐标并裁剪至 [0,512]。

1. 第 1 轮用全局几何距离，按世界推杆位置、T 位置和周期角差排序。输出采用线性残差。
2. 第 2 轮用 T 坐标系里的推杆距离，保留 T 的全局位置和角度距离，三项尺度分别为 30 世界单位、40 世界单位和 15°。这版保留单候选检索与线性残差。第 1 轮离线表明对齐尤其易放大首步误差，换距离用来改善动作先验。
3. 第 3 轮保留第 2 轮的检索，输出改为 `30 × tanh(z)`，限制每步每轴修正量。第 2 轮残差虽降低平均误差，尾部仍有较大偏差。第三轮测试限制修改幅度的效果。

三轮均使用 Adam、种子 42、35 轮、批次 128、学习率 0.001。损失为归一化残差的均方误差，选择最终轮。配置分别在 `configs/round{1,2,3}.json`，公共设置在 `configs/study.json`。第一轮与第二轮的主要差异是检索，第二轮与第三轮的主要差异是残差输出约束。

## 评估与复现

修改方案只参考预留示范。三轮方案固定后统一用官方 Push-T Image Runner 评估。每个条件用同一批 50 个测试种子，每次执行八步，每局最多 300 步。主指标是各局最高 `clip(coverage/0.95, 0, 1)` 的均值，另报末步。重采样以相同测试种子为配对单位。离线动作误差衡量示范一致性，闭环分数衡量实际推物。

```powershell
$python = '..\..\..\DP\.conda\pusht\python.exe'
foreach ($round in 1,2,3) { & $python -B src/study.py train $round }
foreach ($round in 1,2,3) { & $python -B src/study.py evaluate $round }
```

从 `experiments/pusht_residual` 执行。入口拒绝覆盖已存在运行目录。冻结清单和仿真适配器按只读方式使用。检索、动作坐标变换、残差与评估入口集中在 `src/study.py`。仿真真值输入和单模型种子是本诊断的主要限制。
