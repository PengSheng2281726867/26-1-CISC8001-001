# 三轮残差修正结果

**已验证。** 三个残差模型各训练 35 轮，每个模型用 3,596 个跨轨迹训练配对和 2,286 个预留示范查询。三轮各跑三种控制条件，每种条件 50 个正式种子，共 450 局。第 2、3 轮各自复跑了相同的原样和对齐对照。训练与评估实际命令见 [实验说明](EXPERIMENT.md)，运行时间、完整配置、精确轨迹 ID、种子、代码和检查点哈希见 [证据目录](evidence/)。

## 能得出什么

- **相对几何检索结合 T 坐标对齐的闭环表现最好。** 第 2 轮固定检索时，对齐相对于原样回放的配对差为 +0.6753［+0.5808，+0.7663］。这是仿真真值条件下完整闭环的结果。每轮执行后，下一次查询使用策略自己到达的状态。
- **动作模仿误差下降与闭环提升分离。** 第 2 轮的残差有最低离线 RMSE，闭环分数却明显低于对齐。第 3 轮稍微牺牲了平均离线误差，动作修正的闭环块 L2 均值从 145.87 降到 73.89，闭环得分回升 0.2956。这支持限制修正幅度有用。动作是否因平均了不同推法而失效，本实验尚未直接区分。
- **当前残差方案未带来对齐之上的增益。** 监督标签来自人类示范动作差，没直接奖励修正后推动 T 朝目标的效果。若另开一轮，可在同一仿真状态用末步进展比较几种修正后再选标签。当前依照要求停在三轮。

## 验证和范围

`src/verify.py` 检查全部 450 局的种子顺序、逐查询实际步数、训练轨迹归属、动作索引及边界，独立复算坐标对齐、得分均值和残差对齐差的配对区间。第 3 轮的全部修正量通过块范数上限检查。结果在 [verification.json](evidence/verification.json)。运行使用现有 Windows Python 3.10、Torch CPU 和原版官方 Runner。三轮未遇到中止或数值异常，学习残差降低闭环表现如实保留。

几何检索和对齐均使用当前真实 T 位姿。此实验使用单个模型种子，区间衡量评估种子上的差异。图像位姿估计、基于仿真结果学习动作选择、DP 对照都留待后续。权重、原始视频和完整查询日志在 `artifacts/`。
