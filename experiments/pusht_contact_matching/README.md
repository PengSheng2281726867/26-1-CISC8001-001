# Push‑T 推杆相对 T 的几何检索

两种规则遍历同一个冻结训练库（30 条示范、3,806 帧），用仿真器当前 T 位姿作为几何诊断输入。先将推杆中心转换到 T 坐标系，再计算它到 T 外轮廓最近边的距离，减去推杆半径得到间隙。最近边是潜在接触位置的几何线索。

- **相对几何**按 T 的桌面位置误差、周期角差、推杆在 T 坐标系中的距离、间隙误差排序。四项各除以配置中的尺度后平方相加，选全库最小值。
- **同边筛选**优先要求最近边相同，且上述误差分别不超过 60 个世界单位、15°、30 个世界单位、20 个世界单位。合格候选内沿用相对几何排序。没有候选时使用相对几何，并记录缺失。阈值在运行前固定。

评估用原官方 Runner、原 50 个初始种子、最多 300 步。两组都每次原样执行匹配帧的 8 步绝对坐标动作。旧规则分数来自保存的同协议 50 局，配对区间按种子重采样。离线比较用相同的 20 条预留示范查询全库。比较图预先固定首四个种子与第 0、80、160 步，保存实际当前 RGB、同一当前帧的旧规则匹配、新规则匹配和次候选。只有一个合格候选时图只显示该候选。
